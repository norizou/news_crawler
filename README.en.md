# News Crawler (news_crawler)

This project is a horse-racing (keiba) news collection and analysis system for macOS.

The former English README described an earlier AI-news version of this project (30 AI sources, AIA Proxy, Linux/WSL2) and no longer matched the implementation, so it has been replaced by this pointer.

See [README.md](README.md) (Japanese) for setup, CLI usage, and configuration, and [AGENTS.md](AGENTS.md) for design decisions.
